# Supported Networks and Tokens

## Supported networks

Orbitra Exchange supports deposits and withdrawals on these networks:

- Ethereum
- TRON
- Solana
- Polkadot
- Linea

## Supported tokens

| Token | Networks for deposits and withdrawals |
|---|---|
| ETH | Ethereum, Linea |
| USDT | Ethereum, TRON |
| USDC | Ethereum, Solana |
| SOL | Solana |
| DOT | Polkadot |
| TRX | TRON |
| ORB | Ethereum |
| BTC | Trading only |

BTC can be bought, sold and traded on Orbitra, but BTC cannot be deposited to or withdrawn from Orbitra on-chain.

## Not supported

Orbitra does not support:

- Bitcoin Lightning Network
- BNB Chain
- Polygon
- NFTs
- Staking

Tokens sent to Orbitra on an unsupported network are lost and cannot be recovered.

## Memos and tags

A memo or destination tag is not required for any network Orbitra supports.
